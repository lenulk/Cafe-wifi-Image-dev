**กับดักแก้ .docx ด้วย python-docx (เสียเวลามาก):**
- run ภาษาไทยต้องมี `<w:cs/>` ไม่งั้น Word ตัดบรรทัดไทยเฉพาะที่ช่องว่าง (บรรทัดสั้น/ช่องว่างกว้าง) — `lib.fix_cs()` ทำให้ตอน save; อย่าใช้ wordWrap=0 (ตัดคำอังกฤษกลางคำ) และห้ามแทรกอักขระล่องหน
- ย่อหน้าไทยใช้ jc=thaiDistribute (ได้ผลดีหลังมี cs) · รันโค้ด Consolas ต้องไม่มี cs (lib จัดการแล้ว)
- ห้ามค้นหัวข้อด้วย `find(startswith)` ทั้งเอกสาร — ชนบรรทัดในสารบัญแล้วเขียนทับ ใช้ `sec(d, บท, prefix)` ที่ค้นหลังหัวบทจริงเท่านั้น; แทรกตารางใหม่แล้ว `d.tables[i]` ขยับ
- ย่อหน้าตัวแบ่งหน้าว่างท้ายหน้าเต็มจะล้นเป็นหน้าว่าง → ตั้ง 1pt
- ตรวจเสมอบนสำเนา: Word COM → ExportAsFixedFormat → pymupdf (ข้อความไทยใน PDF สระ ำ หายเป็น า ตอน normalize)
